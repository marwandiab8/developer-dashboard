# Setup and runbook

## Prerequisites

- Node.js 20+
- npm

## One-time setup

1. Run `npm install`
2. Run `npm run dev`
3. Open `http://localhost:3000`

## Verification commands

- `npm run lint`
- `npm run typecheck`
- `npm test`
- `npm run build`

## Seed data

On first run with no saved payload, dashboard seeds with:

- GridlineAI
- Time Left To Live
- Developer Dashboard
- Darts Tracker
- Workout App

and seeded ideas/tasks/sessions to make Phase 1A immediately usable.
